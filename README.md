Build the best token launch radar. Read a sealed snapshot of every protocol DefiLlama tracks, work out which ones still record no token and are not a wrapped or staked product of one that trades, and rank them by what their launch would be worth — then hand in a web dashboard that shows the board, a detail view for each protocol and the steps to farm it.

> **Status: REBUILT against the kit's sealed snapshot — not submitted.** The public GitHub repo does not exist yet and the 3 screenshots are not taken. The official `dossier.json` is generated by `main.ts` into the output directory once the screenshots exist. See `VERIFICATION.md` for the full verification log.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts --input ../token-radar-01-kit/input/snapshot.json
```

Node 22.18 or later (tested on Node 24.22.1). Stdlib only — no dependencies, no network at run time. `main.ts` reads the kit's sealed snapshot (`input/snapshot.json`, sha256 `42a71213…`, verified against the kit's `kit.json` before building) and writes to the output directory:

- `board.json` — the board (197 rows: 40 watchlist + 157 early)
- `data.js` — the same board as `window.RADAR` for the dashboard
- `dashboard/` — the static dashboard (3 files, no network)
- `screenshots/` — the 3 screenshots (board, protocol detail, filtered view)
- `dossier.json` — the official dossier, produced by `vendor/makefun-board.ts`

Open `dashboard/index.html` in a browser (with `data.js` beside it). Deep links: `#detail=<slug>` opens a protocol's detail view; `#q=<text>&cat=<Category>&chain=<Chain>&minTvl=<n>` applies filters. The three screenshots are `dashboard/index.html` plain, `#detail=polymarket-international`, and `#cat=Prediction+Market`.

## Method (model `peer-median-1`)

1. **Candidates** — protocols with no token recorded (no market cap, no CoinGecko id, no symbol) and TVL ≥ $50M on the watchlist, plus pre-token protocols the watchlist left off, by TVL. From 758 protocols in the sealed snapshot: 342 with no token, **197 on the board** (40 watchlist + 157 early — the early pool is exhausted after the exclusions below).
2. **Exclusions** — the same rule the house used to build the watchlist, applied to the snapshot's ten fields: categories Bridge, Canonical Bridge, Cross Chain Bridge, Liquid Staking, Liquid Restaking, Restaked BTC and CEX; names ending in a version marker, names containing a whole word wrapped / staked / staking, names beginning with a centralized exchange's brand. No protocol name is special-cased: Lightning Network and Bittensor dTAO are on the watchlist itself and rank here. The snapshot carries no `parentProtocol` field, so that part of the house's rule cannot be applied to early rows.
3. **Valuation** — implied FDV = TVL × median(mcap/TVL of tokenized peers in the same category with TVL ≥ $100k, ≥ 5 peers, else the global median), multiple capped at 10x, FDV capped at $10B. Implied value = implied FDV × launch probability × 7% expected airdrop share. Launch probability: 0.40 base, +0.10 TVL up over 7d, +0.10 listed ≥ 1 year, +0.05 on 3+ chains, clamped [0.10, 0.85]. The sealed snapshot holds only 128 tokenized protocols with a usable market cap and only 9 categories with ≥ 5 peers, so most rows use the global median 0.214x — a property of the sealed snapshot, stated, not hidden.
4. **Farm plan** — 6 concrete steps per row, each with a cost and a time, derived from the protocol's category, chains, TVL and age.

Top of the board: #1 Sentora Curator (Risk Curators, $2.76B TVL, implied value $26.8M) — an early row, not a watchlist row: it has the highest TVL in the snapshot and the house rule left it off the watchlist for a reason the snapshot's ten fields cannot express. #2 Steakhouse Financial (watchlist, $22.7M). Polymarket International ranks #13 ($2.4M) as an early row: $320M TVL and no token, left off the watchlist by the house's own rule — the floor is a watchlist-selection rule, not a board rule, and the rules say protocols left off the list are equally valid subjects.

## Determinism

Re-running `main.ts` on the same sealed snapshot reproduces `out/board.json` and `out/data.js` byte-identically (row order tie-broken by TVL then slug). Verified: two consecutive runs, identical sha256 (see `VERIFICATION.md`).

## Snapshot

The kit's sealed snapshot: `input/snapshot.json` in the unpacked kit (`../token-radar-01-kit/`), as of 2026-11-14, source DefiLlama protocols list, floor $50,000,000, 758 protocols, watchlist 40 slugs — sha256 `42a71213519479f3a180cc5010cbbf6bd18a2447fa0ad29e4c5122b6c9184393` (recorded in the kit's `kit.json`; `main.ts` refuses to build from a file whose hash differs). The earlier local build used a live DefiLlama fetch sealed by hand (9,110 protocols, sha256 `82696120…`); that snapshot is superseded and removed — the board now comes from the kit's snapshot only.

## Limitations

- Implied values are estimates from public comparables, not predictions. The 7% airdrop share and the launch probabilities are stated assumptions, not facts.
- Screenshots (board, protocol detail, filtered view) not yet taken — they need a browser render of the dashboard. Each must be 300–350 KB so the dossier stays under 1.5 MiB.
- No public GitHub repo yet — it must be created after the competition opened (14 Nov 2026) under `slowwilly20`, with the make.fun README badges and About (website on make.fun + topic `makefun`).
- No transcript bundle yet — it needs the kit CLI (`node cli/makefun.mjs bundle`) plus the Muse usage rows; the sessions are the build subagent's, this rebuild session's, and the parent session's.
